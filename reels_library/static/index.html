Relier vos sauvegardes

Le serveur utilise une session Instagram pour lire vos sauvegardes. Une fois la connexion établie, votre ordinateur peut être éteint.

  1. Connectez-vous à votre compte Instagram et préparez un fichier de session au format Netscape. La procédure est décrite dans le guide de déploiement.
  2. Transférez la session ici, puis testez un passage de 50 publications.
  3. Activez les passages réguliers. Vous renouvellerez la session si Instagram le demande.

Les passages continuent tant que le service fonctionne sur le serveur. Une limite atteinte est signalée : les sauvegardes plus anciennes peuvent rester à récupérer. Les références retirées d’Instagram sont conservées dans votre bibliothèque.

Une connexion à valider.

Ce connecteur est expérimental. Instagram peut demander une nouvelle connexion ou limiter l’accès depuis un VPS. Le résultat de chaque passage apparaît ici.

Le fichier de session donne accès au compte : il est conservé séparément sur votre serveur et sert uniquement à contacter Instagram. Il est exclu de l’export de bibliothèque. Aucun média n’est téléchargé.
